# Cascading Style Sheets (CSS) — Learning

`CSS` (**Cascading Style Sheets**) is used alongside HTML to control the visual appearance and layout of web pages.

It can define:

- Colors
- Fonts
- Sizes
- Positioning
- Margins
- Padding
- Borders
- Alignment
- Backgrounds
- Animations

---

## Example

CSS applies styles to HTML elements.

Example:

```css
body {
  background-color: black;
}

h1 {
  color: white;
  text-align: center;
}

p {
  font-family: helvetica;
  font-size: 10px;
}
```

HTML elements can also use unique `id` or `class` attributes so they can be targeted individually by CSS or JavaScript.

---

## Syntax

General CSS syntax:

```css
element {
  property: value;
}
```

Example:

```css
h1 {
  color: white;
}
```

Common CSS properties include:

- `height`
- `position`
- `border`
- `margin`
- `padding`
- `color`
- `text-align`
- `font-size`

---

## Animations

CSS can also be used to create animations and visual effects.

Common animation-related properties include:

- `@keyframes`
- `animation`
- `animation-duration`
- `animation-direction`

CSS animations can range from simple movements to complex 3D effects.

---

## Usage

CSS is commonly used together with JavaScript to dynamically modify the appearance of HTML elements.

Example interaction:

```text
User Interaction
      ↓
JavaScript
      ↓
Modify CSS Properties
      ↓
Visual Change
```

CSS can also be used with:

- `HTML`
- `XML`
- `SVG`
- Mobile UI frameworks

---

## Frameworks

CSS frameworks provide predefined styles and components to speed up web development.

Common frameworks include:

- `Bootstrap`
- `SASS`
- `Foundation`
- `Bulma`
- `Pure`

They help developers create consistent and responsive interfaces without manually styling every element.

CSS frameworks are commonly designed to work alongside JavaScript and provide reusable components for modern web applications.
